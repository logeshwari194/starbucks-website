# ☕ Starbucks Coffee Website

A modern and responsive Starbucks-inspired coffee website built using HTML, CSS, and JavaScript.

## 🌟 Features

- ☕ Modern coffee shop design
- 📱 Responsive layout for mobile, tablet, and desktop
- 🛒 Shopping cart functionality
- 🔥 Preloader with Starbucks logo
- 🖼️ Coffee product images
- 📋 Coffee menu section
- 📞 Contact section
- 🌐 Social media footer
- ✨ Smooth animations and interactive UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap Icons
- Google Fonts
